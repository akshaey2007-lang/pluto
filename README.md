# Pluto

Pluto is a multi-page marketplace prototype for protected fixed-price digital work. It uses the approved **Signal Desk** design system: a charcoal operational menu, crisp data surfaces, and a controlled yellow action accent.

## Start locally

```powershell
npm start
```

Open `http://localhost:3000`.

## Pages

- `index.html` — platform details only
- `how-it-works.html` — marketplace journey
- `talent.html` — Talent Atlas experience
- `clients.html` — client experience
- `protection.html` — milestone protection
- `talent-login.html` and `talent-signup.html`
- `client-login.html` and `client-signup.html`
- `talent-dashboard.html` — feature-rich Talent Signal Desk
- `client-dashboard.html` — feature-rich Client Signal Desk

Authentication forms are interactive prototype flows; production authentication and storage are intentionally not connected yet.
